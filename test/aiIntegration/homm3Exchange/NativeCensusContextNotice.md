# Native census context provenance

`NativeCensusContextBodies.inc` contains verbatim reconstructed functions from
`sushi-shi/homm3-decomp` commit
`e12906accf96c2662b1abadbc49ddc111991bf21`, `src/ai_tactical.cpp`, under CC0-1.0.
The adjacent manifest records the original snapshot and extraction hashes.
The license text is `LICENSE.CC0-1.0` in this directory.

The native adapter preserves the constructor's alive-only global normalization
and the last-action sufficient condition. It does not compile this constructor:
its original difficulty/human underdog branch is not mapped. The caller instead
proves the non-underdog condition before selecting Ray. Native incapacitation
outside the admitted exchange domain conservatively prevents the sufficient
last-action proof rather than being interpreted as a completed action.

The exchange and ranged-candidate source oracles remain separate in
`PinnedExchange.h`; these context bodies document native control-flow provenance,
not additional runtime/differential coverage.
