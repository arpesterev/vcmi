# Live ordinary-shooter forecast withdrawal

Source: sushi-shi/homm3-decomp commit `e12906accf96c2662b1abadbc49ddc111991bf21`, `ai.cpp::aiCheckRetreat`, `simulateCombat`, and `command.cpp::checkGetAIMove`.

The live controller now consumes the ordinary all-shooter two-pass expected-damage ledger for one narrowly defined withdrawal branch. Source `aiCheckRetreat` first checks hero/difficulty/tavern/escape restrictions, then requires artifact value >=1000 OR hero experience >=2000, executes `simulateCombat(side,1)`, and returns true immediately if no non-immobilized, non-siege own troop has positive projected health. This return precedes the surrender-cost reserve and fight-value ratio branch. Source `checkGetAIMove` converts a bot's accepted decision to RETREAT.

The native bridge selects the experience >=2000 arm, so no artifact value, surrender cost, gold reserve or fight-value threshold is invented. It admits only actual AI attackers in open field, Hard/Expert/Impossible difficulty, a standard-win map, an owned tavern, own noncasting hero, no opposing hero, no equipped Shackles, and legal native flee. Human flags, authoritative human ownership, and three-argument human-autocombat initialization block the consumer. Native no-book spell grants also block it.

The forecast uses the existing validated ordinary effective-record capture and exact source two-pass algorithm, including source move order, target selection and expected-damage projection. It is not host midpoint damage, a strength-ratio heuristic, or a combat-to-completion simulation. All living troops must be ordinary available shooters; incapacitation, Berserk, created troops, special roles, unsupported effective modifiers, uncertain phase/order and other existing capture exclusions remain unavailable. Both armies must initially have living troops. Every living own troop must have expected damage at least its current health. A surviving troop means no withdrawal from this consumer.

The call runs on the normal controller battle thread after lifecycle activation and before spells or unit actions. A forecast retreat emits one native command and returns. A declined/unavailable forecast continues existing gameplay; the town/tavern history guard still invalidates source ranks where the original pre-AI simulation could have written them. No new rank history is guessed.

Remaining: mixed/melee forecast withdrawal beyond the certified a43 domain below, artifact-worth eligibility, economic/ratio branch, Normal RNG gate, defending Stronghold tunnel cases, caster/hidden enemy pressure, arbitrary modifiers and broader source simulation parity. The previously accepted failed-siege early branch is unchanged. These are combat-only partial backends, not adventure-map AI or complete original-engine parity.

## a43 ordinary ground/mixed consumer

A second consumer extends the same XP-based annihilation decision to certified ordinary ground/mixed armies. It requires the existing native mixed-history certificate and uninterrupted public static-map geometry, and admits no initial corpses, incapacitated/Berserk troops or special roles. At least one living troop must be a non-shooter; the accepted a42 all-shooter route remains separate. The ordinary native mixed capture proves current public effective records and reachability; the pinned ground two-pass model supplies source melee target selection, retaliation, expected health and source order.

Speculative simulation draws 75..100 factors from a copy of the controller's source-private generator, with a conservative 1024-draw budget. A failed capture/model or changed lifecycle commits nothing. A successful model commits precisely its consumed draw count, including when a survivor causes the hero to stay; this mirrors the pre-AI simulation's RNG side effect. The forecast's hypothetical attacks do not mutate the native battle. Unsupported future draws/order/mechanics remain unavailable rather than falling back to a guessed defeat probability.

This remains the all-own-troops-annihilated source branch, not the artifact-eligibility or economic-ratio branch. Ordinary mixed capture's own noncasting/no-opponent-hero limits still apply. Initial corpse history, broad caster/special armies, defending escape and source RNG seed equivalence remain unclaimed. The source-private generator reproduces the model's draw accounting, not the original executable's global RNG stream.

## a44 bounded loss economics after successful forecast

After an admitted successful shooter or ground two-pass prediction leaves own survivors, the controller can now execute the source economic/fight-ratio retreat arm. Eligibility still requires XP >=2000 and all earlier native/ownership/map checks. Economics is certified only with no carried artifacts, or the sole canonical equipped Catapult; other artifacts, Diplomacy, native surrender discounts and resurrected troop counts are unavailable. This is not general artifact valuation.

Source `command.cpp::getSurrenderCost` sums current own non-summoned troop counts times recruitment gold, divides the total by two, then applies the hero discount factor. At zero Diplomacy and no discount artifacts that factor is exactly one. The source computation exists against a neutral army even though native SURRENDER is unavailable there; this consumer emits RETREAT, not surrender. The required reserve is this source cost plus 2500 gold.

Source fight values use current original living troop counts and base fight values, not projected remaining HP or native AI-value scaling. `army.h::isActive` is `m_creatureType >=0 && m_numTroops>0`. The forecast writes expected damage/order/action scratch, not live troop counts or creatureDone; the 1.2 not-done multiplier and 1.1 opponent multiplier retain their source integer truncation. Threshold uses source float assignments, Hard+ difficulty, integer `m_experience / 200000` before conversion and the attacker deduction. Strict `ratio < threshold` and inclusive reserve `gold >= cost+2500` are preserved. Overflow or unsupported inputs decline.

The ordinary Catapult is deliberately NOT valued zero: `ai_player.cpp` gives it no per-hero artifact effects, `aiGetEquipValue` remains zero, but the player-level `aiGetValueOfArtifact(artifact,player)` initializes its best value to TEN. Its canonical price is 1000, so `max(value,price/2)` is exactly 500 and activates the source positive-artifact threshold increment of `0.04f`. The native guard admits only one unlocked MACH4 Catapult ID3 with price 1000, no backpack/transition artifact and no other equipment. The full source artifact-effect definition stream contains no Catapult ID3 row. Custom Catapult valuation is not claimed.

Native fixtures and scalar oracle tests must distinguish a surviving predicted army retreat from annihilation, exact reserve and one-gold-short boundaries, default-Catapult versus empty-inventory threshold, and unsupported artifact/discount state. General artifact value eligibility, defended-town economic branches, caster pressure and broad special-unit parity remain incomplete.
